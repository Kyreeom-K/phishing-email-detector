# Phishing Email Detection Model

A machine learning model built with **Scikit-learn** that classifies emails as **Phishing** or **Safe** based on their text content and URL/keyword-based features.

## Key Features
- Trains on a dataset of phishing and legitimate emails
- Extracts and analyzes email features: TF-IDF text vectors + engineered features (URL count, suspicious keywords, exclamation marks, uppercase ratio, etc.)
- Classifies emails as "Phishing" or "Safe" using Logistic Regression
- Displays accuracy and a confusion matrix (printed + saved as an image)

## Files
- `phishing_detector.py` — the full pipeline: data loading, feature extraction, training, evaluation
- `confusion_matrix.png` — example output image (generated by the script)
- `README.md` — this file

## How to run

```bash
pip install scikit-learn pandas matplotlib scipy numpy
python3 phishing_detector.py
```

This runs with a **built-in sample dataset** (templated phishing vs. legitimate emails) so it works out of the box with no setup. It will print accuracy, a classification report, and a confusion matrix, and save `confusion_matrix.png`.

### Using a real dataset (recommended for stronger results)

The built-in sample dataset is small and templated, so the model scores unrealistically high (100%) on it — that's expected for a demo dataset, not a bug. For a more meaningful evaluation, download a real phishing email dataset and pass it in:

```bash
python3 phishing_detector.py --data your_dataset.csv
```

Your CSV needs two columns:
| column | description |
|---|---|
| `text`  | the email subject + body as one string |
| `label` | `phishing` or `safe` (or `1`/`0`) |

Good sources for real datasets:
- Kaggle: "Phishing Email Detection" dataset
- Kaggle: Nazario Phishing Corpus (phishing) + Enron Email Dataset (legitimate)
- UCI Machine Learning Repository: Phishing Websites Dataset

## How it works
1. **Feature extraction** — TF-IDF vectorizes the email text (unigrams + bigrams), combined with hand-crafted features: number of URLs, presence of an IP-address URL, count of suspicious keywords ("urgent", "verify", "suspended", "click here", etc.), exclamation marks, message length, and uppercase-letter ratio.
2. **Model** — Logistic Regression with balanced class weights.
3. **Evaluation** — accuracy score, precision/recall/F1 report, and a confusion matrix (printed to console and saved as `confusion_matrix.png`).
